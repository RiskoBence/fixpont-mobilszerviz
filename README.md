# FixPont Mobilszerviz – promóciós weblap

Egyoldalas, reszponzív promóciós weblap a „FixPont Mobilszerviz” kitalált mikrovállalkozáshoz
(Informatika alapjai – projektmunka, 3. rész).

**Technológia:** tiszta HTML + CSS + egy kis JavaScript, külső függőség és build lépés nélkül.

## Tartalom

- `index.html` – az oldal
- `css/style.css` – megjelenés (reszponzív, mobilbarát)
- `js/main.js` – mobilmenü, árbecslő, nyitvatartás-jelző, űrlap
- `img/` – illusztráció
- `dokumentumok/` – a projekt dokumentumai (cégbemutató, forgalmi munkafüzet, PPT, PAD)

## Megtekintés

Nyisd meg az `index.html` fájlt böngészőben, vagy használd a GitHub Pages-es linket.
